# 01. 产品需求规格（PRD）

## 1. 产品定义

### 1.1 一句话定位

方迹是一款完全离线的 Android 魔方工具，把 CFOP 公式管理、针对性训练、V10 AI 实拧记录和可解释的赛后复盘连成一个闭环。

### 1.2 核心用户

- 第一用户：应用所有者本人，熟悉或正在学习 3×3 CFOP。
- 第二用户：几十位朋友组成的小圈子，设备和水平可能不一致。
- 默认假设：用户能理解基本转动记号，但不需要理解蓝牙、数据库或开源许可证。

### 1.3 用户要完成的工作

1. 快速找到某个 F2L、OLL 或 PLL case 的首选公式。
2. 把自己的公式、手法提示、标签和掌握程度保存下来。
3. 针对生疏 case 反复识别和执行，并看到进步。
4. 用手动或 V10 AI 计时，可靠保留每一次成绩。
5. 回看真实动作与魔方朝向，找到停顿多、步数高或执行不稳定的阶段。
6. 在没有网络和账号的情况下备份、升级和迁移数据。

## 2. 产品原则

- 离线是真实约束，不是“断网降级模式”。
- 原始记录不可被分析结果替代；算法升级后可以重算。
- 展示事实和置信度，不把启发式判断包装成确定结论。
- 学习闭环比功能数量重要。
- 真机一致性优先于动画顺滑；画面与真实魔方不一致时必须显式提示并恢复。
- 预设内容和用户内容分层，应用升级不得覆盖用户选择与笔记。
- 首版围绕单设备做深，不为尚未支持的品牌提前堆砌复杂抽象。

## 3. 功能范围与需求

### 3.1 公式库（LIB）

| ID | 优先级 | 需求与验收 |
|---|---|---|
| LIB-001 | P1 | 内置 41 F2L、57 OLL、21 PLL，共 119 个唯一 case；每个 case 有稳定 ID、名称、分类、规范局面和至少一个已校验公式 |
| LIB-002 | P1 | 按 F2L / OLL / PLL、掌握度、收藏、标签和是否到期筛选 |
| LIB-003 | P1 | 支持中文名、英文别名、case 编号和公式文本搜索 |
| LIB-004 | P1 | case 卡片显示程序生成的局面图、名称、首选公式摘要和掌握度，不使用参考海报裁图 |
| LIB-005 | P1 | 详情页展示可旋转三维魔方、逐步演示、公式分词、变体、笔记、标签和训练入口 |
| LIB-006 | P1 | 每个 case 可新增、复制、排序、停用公式变体，并指定唯一首选公式 |
| LIB-007 | P1 | 预设公式允许被用户“覆盖选择”，但预设原文保持只读，方便版本升级和恢复 |
| LIB-008 | P1 | 公式编辑时实时解析；非法 token、括号不匹配或执行后不能得到目标结果时，不允许标为已验证 |
| LIB-009 | P1 | 支持 U D L R F B、prime、2、宽层、M E S 和 x y z；扩展记法必须先经过解析测试 |
| LIB-010 | P2 | 支持导入、导出一组自定义 case 和公式变体 |
| LIB-011 | P2 | 提供“本次升级新增或修改了哪些预设公式”的变更摘要 |

case 的“局面”必须是完整 54 facelet 状态或等价的 cubie 状态，不得只保存一张图片。公式校验需要考虑观察朝向、预置 AUF 与结束 AUF。

### 3.2 训练（TRN）

| ID | 优先级 | 需求与验收 |
|---|---|---|
| TRN-001 | P1 | 提供识别训练：显示局面，用户选择 case 或先在心中识别后揭示答案 |
| TRN-002 | P1 | 提供执行训练：按筛选集合随机出题，记录反应时间、执行时间、正确性和使用的公式 |
| TRN-003 | P1 | 无智能魔方时允许手动判定正确 / 失误；有 V10 AI 时由最终局面自动校验 |
| TRN-004 | P1 | 支持仅训练收藏、生疏、到期、某标签或用户勾选的 case |
| TRN-005 | P1 | 每次训练后更新掌握度和下次复习时间，并允许撤销误判 |
| TRN-006 | P1 | 训练页可一键打开 case 详情，不丢失当前训练队列 |
| TRN-007 | P2 | 智能魔方训练中提示错转位置，但默认不在动作发生前泄露下一步 |
| TRN-008 | P2 | 支持固定次数、固定时长和“清空今日到期”三种训练目标 |

首版采用可解释的五级复习箱，不引入难以调试的黑盒推荐：

| 等级 | 建议间隔 |
|---:|---:|
| 0 | 当前训练再次出现 |
| 1 | 1 天 |
| 2 | 3 天 |
| 3 | 7 天 |
| 4 | 14 天 |
| 5 | 30 天 |

错误降一级；连续正确升一级；用户可手动调整。反应明显过慢时记录“正确但迟疑”，不自动判错。

### 3.3 计时（TMR）

| ID | 优先级 | 需求与验收 |
|---|---|---|
| TMR-001 | P1 | 生成合法 3×3 scramble，支持复制和重新生成 |
| TMR-002 | P1 | 手动模式支持按住准备、松手开始、再次触碰停止，并防止普通滚动或返回误触 |
| TMR-003 | P1 | 可选 15 秒观察；按本地规则显示 8 秒和 12 秒提示，超时可标记 +2 / DNF |
| TMR-004 | P1 | 智能模式中，scramble 状态匹配后进入 Ready；第一步真实转动开始计时，解出自动停止 |
| TMR-005 | P1 | 未完全打乱、连接断开或状态不同步时不得静默开始，必须给出可恢复提示 |
| TMR-006 | P1 | 停止后提供保留、+2、DNF、删除、备注和标签；删除需短时撤销 |
| TMR-007 | P1 | 支持会话，展示当前单次、最佳、平均、ao5、ao12、ao100 |
| TMR-008 | P1 | 支持检查和编辑本次 scramble、计时来源和惩罚 |
| TMR-009 | P2 | 支持外接蓝牙计时器不在首版范围；只预留 SolveSource 枚举 |

所有显示成绩保存原始毫秒数和惩罚，不把加罚后的字符串作为唯一数据。

| 设置 | 默认值 |
|---|---|
| Cross 颜色 | 白 |

| move 计数 | HTM |

## 5. 权限与隐私

### Android 12 及以上

- BLUETOOTH_SCAN：发现附近 V10 AI。
- BLUETOOTH_CONNECT：连接并交换 GATT 数据。
- 若实现不从扫描结果推导位置，声明 neverForLocation。

### Android 11 及以下

按系统要求使用带 maxSdkVersion 30 的旧蓝牙和位置权限；仅在扫描需要时申请，不保存位置，也不展示误导性用途。

应用不得申请：

- INTERNET。
- 后台定位。
- 通讯录、相册全库、电话、麦克风或摄像头。

文件备份使用系统文件选择器的单文件授权，不申请“所有文件访问”。

## 6. 非功能指标

| 类别 | 首版目标 |
|---|---|
| 冷启动 | 中端真机常规冷启动小于 2 秒 |
| 公式列表 | 119 个 case 全量滚动保持流畅，不为每张卡片创建 WebView |
| BLE 连接 | 已配对 profile 的常规连接中位数小于 5 秒 |
| move 延迟 | 设备事件到逻辑状态更新 P95 小于 100 ms |
| 实时渲染 | 前台目标 60 fps；低性能设备允许自适应到 30 fps |
| 一致性 | 发现 move 序号空洞后 2 秒内尝试完成状态重同步 |
| 稳定性 | 连续 100 次计时无崩溃、无数据库损坏 |
| 数据规模 | 10,000 个 Solve 时列表、筛选和备份仍可用 |
| 可访问性 | 常用触控目标至少 48 dp；支持字体放大、屏幕阅读器和降低动态效果 |
| 离线性 | 飞行模式和无 SIM 情况下，除系统蓝牙限制外全部核心功能可用 |

指标以真机基准测试为准。若动画与正确性冲突，正确性优先。

## 7. 产品级异常处理

| 情况 | 用户看到的结果 |
|---|---|
| 未授予附近设备权限 | 解释用途并提供“去授权”；公式和手动计时仍可用 |
| 蓝牙关闭 | 页面内提示“打开蓝牙”，不跳转到空白页 |
| 设备在其他 APP 中连接 | 给出断开其他 APP 后重试的具体建议 |
| MAC 或解密失败 | 标记“设备识别失败”，允许手动校验设备信息并导出诊断 |
| move 丢失 | 立即暂停“已同步”状态，请求完整局面；本次数据标异常 |
| gyro 无效 | 保留 move 跟踪，切换为锁定视角，不阻断计时 |
| WebView 渲染失败 | 核心计时和记录继续工作，显示静态局面与重载入口 |
| 存储空间不足 | 停止高频采样，保留 move 和计时，提示导出或清理 |
| 备份损坏 | 在写数据库前失败，并说明具体检查项 |
| 应用升级迁移失败 | 不清空数据；进入只读恢复页并允许导出数据库诊断 |

## 8. 成功标准

首个可分享版本不是以“页面数量”验收，而以以下闭环验收：

1. 用户从记录中找到一个 F2L 薄弱点。
2. 一步进入对应 case，选定或编辑自己的首选公式。
3. 完成一组训练，正确率和执行时间被记录。
4. 用 V10 AI 完成新的 Solve。
5. 复盘中能看到该阶段的时间、动作和停顿变化。
6. 所有数据可在飞行模式下备份，并在另一台 Android 设备完整恢复。
