# 02. 信息架构与交互规范

## 1. 导航结构

底部固定四个一级入口：

| 入口 | 主要任务 | 默认首页 |
|---|---|---|
| 公式 | 查找、管理和演示 case | 最近使用 + F2L / OLL / PLL 分类 |
| 训练 | 识别和执行专项训练 | 今日到期与自选集合 |
| 计时 | 手动或智能魔方实拧 | 当前 session 的计时台 |
| 记录 | 查看成绩、统计和复盘 | 当前 session 摘要与最近 Solve |

右上角或上下文入口：

- 设备：在训练与计时页显示为状态胶囊，点击进入连接面板。
- 设置：从各一级页右上角进入。
- 备份、许可证和诊断：设置内二级入口。

导航原则：

- 切换一级入口保留各自滚动位置、筛选条件和草稿。
- 正在计时、导入或固件握手时，不因误触底部导航而丢失状态。
- Android 返回先关闭弹层，再退详情，最后按系统规则退出。
- 不使用隐藏的主功能侧滑菜单。

## 3. 整体布局概念

产品采用“计时工作台”而不是通用卡片流：

- 页面上部始终回答“我现在在哪、设备是否可信”。
- 页面中部只保留当前任务的主要对象：case、计时数字或三维魔方。
- 页面下部提供连续操作：公式 token、Move Rail、训练反馈或成绩操作。
- 统计页以对比和时间轴为主，避免把每个数字都包成独立圆角卡片。

手机竖屏是主形态；横屏用于计时台和复盘的扩展视图，不要求平板专属布局，但宽度超过 720 dp 时使用左右双栏。

## 4. 标志性交互：Move Rail

Move Rail 是本产品贯穿实时跟踪、训练和复盘的核心视觉语言。

### 4.1 组成

- 每个 move 是一个等宽 token。
- 相邻 move 的水平距离按真实时间映射；长停顿显示为空隙和毫秒标签。
- Cross、F2L、OLL、PLL 作为轨道底色或顶部细线，不替代文字标签。
- 整体转体 x / y / z 以较窄的空心 token 表示。
- 丢失事件、重同步和人工修正用带图标的断点表示。
- 当前播放位置是一条高对比游标，并与三维画面和指标联动。

### 4.2 行为

- 左右拖动改变回放时间；轻点 token 跳到动作前。
- 双指缩放只在复盘页启用，用于改变时间尺度。
- 实时计时中自动跟随末尾；用户手动回看后出现“回到实时”按钮。
- 屏幕阅读器将 token 读作“第 18 步，R prime，F2L，距上一步 310 毫秒”。
- 降低动态效果开启后，游标和三维魔方使用离散步进。

## 5. 页面规格

### 5.1 公式首页

顶部：

- 标题“公式”。
- 搜索入口。
- 设置入口。

内容：

- 最近使用横向短列表，最多 6 个。
- F2L、OLL、PLL 分段选择器及数量。
- 筛选行：全部、到期、生疏、收藏、标签。
- case 使用紧凑两列卡片；大字号或窄屏自动单列。

卡片必须包含：

- 程序生成的局面图。
- case 名和编号。
- 首选公式的首行，溢出不超过两行。
- 掌握度的文字与小型进度，不只用颜色。

长按不是必要操作。收藏、训练、编辑等重要功能均须有可见入口。

空状态：

- 搜索无结果：“没有匹配的 case”，保留清除筛选按钮。
- 自定义标签为空：解释标签用途并提供“新建标签”。

### 5.2 Case 详情

竖屏由上到下：

1. 标题、收藏和更多菜单。
2. 约占可用高度 32% 的三维魔方，可拖动观察。
3. 播放控制：上一步、播放 / 暂停、下一步、速度。
4. 当前首选公式，按 token 显示；当前动作高亮。
5. 公式变体列表。
6. 手法提示、用户笔记、标签和训练记录。
7. 底部主按钮“练这个 case”。

变体行清楚区分：

- 预设 / 用户自建。
- 已校验 / 未校验。
- 首选 / 其他。

编辑公式时，解析错误直接贴近 token，不用只显示顶部 Toast。

### 5.3 训练计划

首屏回答三个问题：

- 今天有多少到期 case？
- 我想训练哪一组？
- 本轮做几次或多久？

推荐入口顺序：

1. 今日到期。
2. 生疏项。
3. 自选集合。
4. 按 F2L / OLL / PLL。
5. 标签。

训练配置使用一页内渐进展开，默认值可以直接开始；避免用多页向导。

### 5.4 识别训练

- 中央只显示大局面和必要朝向提示。
- 主动作是“显示答案”或选择 case。
- 揭示后显示首选公式、正确答案和“没认出 / 迟疑 / 熟练”三个评价。
- 用户点“没认出”后，本轮稍后再次出现，不立即连续重复。
- 可暂停并进入 case 详情，返回后恢复队列。

### 5.5 执行训练

状态流：

    准备局面 → 等待开始 → 执行 → 校验 → 反馈 → 下一题

- 无设备时，用户按住准备并手动结束。
- 有设备时，APP 指导把魔方设置到目标局面；状态匹配后自动 Ready。
- 真实第一步开始计时，目标状态完成后停止。
- 错转时保持计时，完成后展示首次偏离位置；除非开启指导模式，不即时泄露解法。

### 5.6 计时台

正常竖屏：

- 顶栏：session 名称、V10 状态胶囊、更多。
- scramble：完整可读，点击展开逐 token 指导。
- 中央：占主导的大号时间。
- 可选三维魔方：智能模式显示；手动模式可折叠。
- 底部：最近 5 次迷你列表与当前 ao5。

计时状态必须用文字与视觉同时表达：

| 状态 | 主文案 |
|---|---|
| Idle | 按住准备 |
| Holding | 继续按住 |
| Ready | 松手开始 |
| Inspection | 观察 14.32 |
| Smart scramble mismatch | 还差 3 步完成打乱 |
| Running | 12.483 |
| Syncing | 正在恢复魔方状态 |
| Stopped | 12.483，等待确认 |

智能模式中，连接状态不得遮挡大号时间；严重异常采用紧凑横幅，不使用阻断整屏的对话框。

### 5.7 成绩确认

停止后从底部升起确认面板：

- 大号成绩。
- 保留、+2、DNF。
- 备注与标签。
- “查看复盘”主入口。
- 删除放在更多菜单中，操作后提供撤销。

正常成绩可在短暂倒计时后自动保留；含异常、断连或同步恢复的成绩必须人工确认。

### 5.8 记录首页

顶部为 session 选择和日期范围。主体按顺序：

1. 当前摘要：次数、最佳、平均、ao5、ao12。
2. 一张可切换指标的趋势图。
3. 最近 Solve 表格化列表。

Solve 行显示时间、惩罚、日期、来源和完整性。避免只用红绿箭头表示变好或变差。

### 5.9 Solve 复盘

竖屏布局：

- 顶部 40%：三维魔方与播放控制。
- 中部：可缩放 Move Rail。
- 下部：阶段表和诊断条目。

阶段表优先使用可比较的列：

| 阶段 | 时间 | 动作 | TPS | 最长停顿 | 置信度 |
|---|---:|---:|---:|---:|---|

点击任一阶段，Move Rail 缩放到该区间，三维回到阶段起点。用户修正边界时显示“自动值”和“当前值”，可恢复自动分析。

### 5.10 设备面板与校准

连接面板不是独立一级页。底部抽屉依次显示：

- 当前设备名、连接状态、电量、固件。
- 连接 / 断开 / 重试。
- 同步局面。
- 重新校准朝向。
- 设备详情与诊断。

首次校准使用三步实物引导：

1. 黄面朝上、蓝面朝前放稳。
2. 点击“设为正面”。
3. 按提示分别向右、向前旋转，APP 验证轴向。

只说“请校准四元数”不合格。

## 6. 关键用户流程

### 6.1 首次使用

    欢迎说明
      → 选择 Cross 颜色与经验水平
      → 进入公式首页
      → 可跳过的“连接 V10 AI”
      → 若连接：授权 → 扫描 → 握手 → 三轴校准 → 测试转动

不强迫首次连接设备。用户跳过后，公式、训练和手动计时完整可用。

### 6.2 智能魔方完整 Solve

    选择 session
      → 连接状态 Ready
      → 生成 scramble
      → 根据 move 或状态确认打乱完成
      → 观察
      → 第一 move 开始
      → solved 状态停止
      → 保存原始数据
      → 后台本地分析
      → 成绩确认 / 查看复盘

若中途断连：

- 计时继续使用单调时钟。
- 标记数据空洞。
- 短时重连成功后请求全量状态。
- 不能恢复的精细区间显示“不完整”，不得补造 move。

### 6.3 从复盘到训练

    Solve 复盘
      → 点击某阶段或疑似薄弱 case
      → 打开 case 详情
      → 加入临时训练清单
      → 完成训练
      → 返回记录时显示最近训练状态

## 7. 反馈与确认规则

- 可撤销的小操作用 Snackbar，例如删除记录、取消收藏、变更标签。
- 数据覆盖、恢复备份和清除全部数据必须二次确认，并明确影响数量。
- 连接和重同步用持久状态，不用稍纵即逝的 Toast。
- 成功不滥用对话框；失败必须说明“发生了什么、数据是否安全、下一步能做什么”。
- 所有加载状态保留页面骨架；连接等待超过 10 秒后显示取消和诊断入口。

## 8. 文案规范

使用动作和结果，不使用内部术语：

| 不推荐 | 推荐 |
|---|---|
| GATT connection failed | 无法连接魔方，请确认它没有连接到其他 APP |
| Quaternion calibration | 校准手持方向 |
| Resync facelets | 正在恢复魔方状态 |
| Analyzer confidence low | 这次分段可能不准确 |
| Delete entity | 删除这次成绩 |
| Start training session | 开始训练 |

公式记号、HTM、TPS 等领域术语可保留，但首次出现提供短解释。

## 9. 可访问性与人体工学

- 主触控目标至少 48 × 48 dp，间距至少 8 dp。
- 大号计时数字不因系统字体放大而被裁切。
- case 的颜色面同时可开启字母或纹理辅助，支持色觉差异用户。
- 颜色不作为“已连接、错误、掌握”的唯一提示。
- 所有三维操作有按钮替代：置正、上一步、下一步和播放。
- 支持 TalkBack 顺序，Move Rail 提供阶段摘要和动作级读取。
- 支持系统“移除动画”和应用内“低动态模式”。
- 振动、声音和视觉提示均可独立关闭。

## 10. 横屏与大屏

| 场景 | 横屏布局 |
|---|---|
| 计时 | 左侧 scramble 与状态，右侧大号时间和三维魔方 |
| Case 详情 | 左侧三维和播放，右侧公式、变体和笔记 |
| 复盘 | 左侧三维，右侧阶段表；Move Rail 跨底部全宽 |
| 公式列表 | 3–4 列紧凑网格，筛选固定在顶部 |

横竖屏切换不得重置计时、播放进度、连接或未保存编辑。
