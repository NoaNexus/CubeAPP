# 11. 当前水平估计与赛前、赛后反馈规划

> 文档状态：实施规划基线
> 文档版本：1.0
> 调研日期：2026-08-19
> 适用范围：3×3 CFOP、魔域 V10 AI、完全离线 Android APP
> 依赖规范：01、02、04、05、06、08、10

## 1. 目的与冻结结论

本规范冻结三个产品变化：

1. 每次智能魔方还原结束后，先显示成绩、总步数、总 TPS、停顿率和显眼的“深度分析”按钮；完整七段 CFOP 分析放在下一层。
2. “下一把多少可以刷新 ao5 / ao12”不再以记录页为主要入口，而是在打乱完成、计时开始之前显示。
3. 新增完全离线的当前水平估计器 `CubeTrace Skill State v1`，简称 `CTSS-1`。它同时利用长期历史与近期状态，预测总用时、实战 TPS、执行 TPS，以及 `C / F1 / F2 / F3 / F4 / O / P` 的当前水平与区间。

本文只定义产品、算法、数据和验收，不授权本任务编写代码。后续开发任务必须在：

    C:\CodexProjects\CubeAPP

中执行。

## 2. 术语与表达边界

### 2.1 不使用“真正 TPS”作为绝对真值

智能魔方能观察动作和时间，不能直接观察视线、思考、手指受力或锁死原因。因此 APP 使用两个明确口径：

| 用户名称 | 定义 | 用途 |
|---|---|---|
| 实战 TPS（含停顿） | HTM ÷ raw Solve time | 表示真实还原结果，默认主指标 |
| 执行 TPS（估算） | HTM ÷（raw time - 规则定义的 pause time） | 帮助区分转动执行与无动作时间 |

“执行 TPS”必须带“估算”字样，并显示停顿阈值。不得命名为手速、手指 TPS 或纯转速。

### 2.2 当前水平的定义

“当前水平”指：

> 在同一统计范围和正常练习条件下，用户下一次还原可复现表现的概率分布。

它不是最佳成绩、平均成绩的改名，也不是对用户能力的永久评级。标准输出包含：

- 预测中位数，而不是只给单点均值。
- 50% 常见区间与 80% 合理区间。
- 样本数、可信状态、模型版本和最近更新时间。
- 长期稳定水平与近期状态的方向，例如“近期比稳定水平快约 0.4 秒”。

用户文案统一使用“当前可复现水平（估计）”，不使用“真实实力”“必定达到”或“AI 证明”。

## 3. 赛后即时反馈

### 3.1 信息层级

完整智能 Solve 停止后，成绩确认面板按以下顺序展示：

```text
12.438            本次 PB
55 HTM     4.42 TPS     停顿 17.0%
[ 深度分析 ]
保留   +2   DNF   备注/标签   更多
```

规则：

- 成绩始终最大；PB / +2 / DNF 是其相邻状态，不另建抢占视觉的大卡片。
- 第二行固定为总 HTM、实战 TPS、停顿率。横屏或宽屏可以增加最长停顿。
- “深度分析”是唯一高强调主按钮，进入 C/F1–F4/O/P、Move Rail、三维回放和提速建议。
- 保留、+2、DNF、备注和删除仍可用，但视觉层级低于深度分析。
- 若分析仍在计算，按钮显示“分析中…”，基本成绩确认不被阻塞；完成后原位变为“深度分析”。
- 正常成绩可按现有规则自动保留；点“深度分析”前先确保 Solve 已落库，避免页面切换丢失。

### 3.2 降级矩阵

| 数据状态 | 即时显示 | 深度分析 |
|---|---|---|
| 智能魔方、move 完整 | 成绩、HTM、TPS、停顿率 | 可用 |
| 智能魔方、阶段边界低置信 | 总体可靠项；异常项显示“数据不完整” | 可打开，但隐藏受影响阶段精确值 |
| move 序列存在不可恢复 gap | 成绩；能证明可靠的总步数才显示 | 显示“本次转动记录不完整”并降级 |
| 手动计时 | 只显示成绩、惩罚、PB | 不伪造 HTM/TPS；按钮改为“查看记录” |
| DNF 且未完成还原 | DNF、raw time（详情） | 不进入完整七段水平更新 |

### 3.3 行为事件

至少记录以下本地事件，用于离线产品调试，不作为联网遥测：

- `SOLVE_SUMMARY_SHOWN`。
- `DEEP_ANALYSIS_OPENED`。
- `DEEP_ANALYSIS_READY_MS`。
- `SOLVE_PENALTY_CHANGED`。
- `ANALYSIS_DEGRADED_REASON`。

这些事件仅进入本机诊断数据库；默认备份可带聚合计数，不导出用户行为流水。

## 4. 赛前纪录追逐提示

### 4.1 出现时机

提示必须满足全部条件后出现：

1. 已生成并冻结本把 scramble。
2. 手动模式进入 Ready 前，或智能模式已确认实体魔方与目标 scramble 一致。
3. 当前 session / scope 已确定。
4. 计时尚未开始。

智能模式的推荐状态顺序：

```text
ScrambleGenerated → Scrambling → ScrambleMatched
→ PreSolveTargetVisible → Inspection/Ready → Running
```

进入 Running 后立即隐藏。本把目标一旦显示，在计时开始前保持静态；后台统计重算不得让数字跳动。

### 4.2 展示规格

计时台在 scramble 与大号时间之间显示一条紧凑的“本轮目标”：

```text
本轮目标   ao5 PB ≤ 11.842   ·   ao12 本窗口无机会
```

可能状态：

- `ao5 PB ≤ 11.842`。
- `下一把 DNF 也仍可刷新 ao5`。
- `ao12 本窗口无机会`。
- `还需 4 次形成 ao12`。
- `暂无 ao5 纪录`。

规则：

- 同屏最多突出 ao5、ao12 两项；详细推导仍可在记录页查看。
- 提供“显示纪录追逐提示”开关，默认开启。
- 专注模式默认隐藏该条，不影响内部计算。
- TalkBack 朗读完整含义，不只读小于号。
- 阈值是最终成绩阈值；若最终被判 +2，用户 raw time 需再少 2 秒。
- 不在 Running 中显示差多少，避免把练习变成实时焦虑反馈。

### 4.3 与 scramble 难度的关系

P1 的 PB 阈值只由历史窗口和正式 aoN 规则决定，不按 scramble 难度篡改。

P2 可另外显示“Cross 难度参考”，例如最短 Cross HTM 与可选解数量，但只能作为解释性辅助变量。由于 F2L 选择、OLL/PLL case 和执行路径在赛前未知，不用它给整把成绩做过度校正。

## 5. 当前水平页面

### 5.1 记录首页卡片

记录首页顶部增加“当前水平”卡片：

```text
当前可复现水平（估计）
12.6 s       常见范围 11.9–13.5
实战 TPS 4.5 · 执行 TPS 5.7（估算）
近期状态 ↑ 0.4 s     可靠 · 38 次智能成绩
```

点击进入“水平详情”。卡片不得显示超过用户可理解的信息，不在首页放模型参数。

### 5.2 水平详情

详情按顺序显示：

1. 总用时、实战 TPS、执行 TPS、步数、停顿率的中位预测和区间。
2. 长期稳定水平与近期状态，明确近期状态会衰减。
3. 七段水平，使用七行横向区间条；不使用难以精确比较的雷达图作为唯一视图。
4. 每段的预测时间、占比、实战 TPS、执行 TPS、停顿率和样本数。
5. 最近一次预测误差、滚动回测表现和“为何可能不准”。
6. 模型版本、scope、数据完整性和重建入口。

| C | 1.62 | 1.35–2.01 | 4.3 | 9% | 可靠 |
| F1 | 1.74 | 1.40–2.20 | 4.1 | 18% | 可靠 |
| … | … | … | … | … | … |

### 5.3 样本门槛

按相同 scope 中可用观察数决定展示：

| 有效样本 | 状态 | 页面行为 |
|---:|---|---|
| 0–4 | 建立中 | 不给数字水平，只说明还需多少次 |
| 5–11 | 初步 | 可给宽区间，明确“波动较大” |
| 12–29 | 可参考 | 展示预测和模型区间，不宣称已校准 |
| ≥30 | 已校准候选 | 通过回测门槛后显示“可靠”；否则仍标“可参考” |

每个 phase 单独计算样本数。总水平可参考不代表七段都可靠。

## 6. CTSS-1：双时间尺度稳健状态模型

### 6.1 为什么不用神经网络

个人离线数据通常只有几十到几千次，分布还会随训练、休息、设备和方法变化。首版采用可重建、可回测、参数量小的状态空间模型，而不是需要外部人群数据的神经网络。

CTSS-1 的目标不是“看起来先进”，而是同时做到：

- 长期历史不会被最近一两把覆盖。
- 近期进步能在数把内逐渐反映。
- 爆炸成绩、意外停顿和 DNF 不把水平拉歪。
- 每次预测都有不确定区间。
- 所有状态都可从 Solve 事实重放得到。

### 6.2 模型对象

为以下对象分别维护状态：

- 总体：raw time、HTM、pause rate。
- 七段：phase time、phase HTM、phase pause rate。
- 必要的完整性、DNF 和样本计数不进入同一连续状态，而作为质量统计。

TPS 不作为完全独立、可能自相矛盾的主预测，而由联合预测样本推导：

```text
practicalTps = predictedMoves / predictedTime
activeTps = predictedMoves / (predictedTime * (1 - predictedPauseRate))
```

这样预测的时间、步数、停顿率和 TPS 保持数学一致。

### 6.3 双状态

对每个变换后的指标维护二维隐状态：

```text
x_t = [A_t, F_t]ᵀ
A_t = A_(t-1) + ε_A              // 长期稳定水平，变化慢
F_t = decay(Δt) · F_(t-1) + ε_F  // 近期状态，变化快且会衰减
y_t = A_t + F_t + ε_y            // 本次观察
```

- `A` 是长期稳定水平。
- `F` 是近期状态；持续训练可使其保持，长时间不练时逐渐回到 0 且不确定性增大。
- 当前预测为 `A + F`。
- `ε_A` 的过程方差小于 `ε_F`，具体参数通过历史滚动回测确定，不手填“万能常数”。
- 时间间隔同时参考“距离上次有效 Solve 的天数”和“有效 Solve 序号”，避免一天刷 100 把与一个月只练 5 把被视为同一节奏。

### 6.4 变换

为保证范围合法并减轻偏态：

| 指标 | 模型空间 |
|---|---|
| time、move、正值间隔 | `log(max(value, epsilon))` |
| pause rate | 截断到 `(0,1)` 后使用 `logit` |
| skip 的 phase time / move | 作为 skip 分类事实，不把 0 送入对数连续状态 |

显示时做逆变换。模型内部使用 Double；数据库保留原始整数毫秒/纳秒和整数 move，不以浮点预测替代事实。

### 6.5 稳健更新

P1 实现使用可审计的 Huber 化 Kalman 更新：

1. 计算预测残差 `r` 与标准化残差 `z = r / sqrt(S)`。
2. 使用 `w = min(1, c / abs(z))` 降低极端观察权重。
3. 等价地放大观察噪声 `R_eff = R / w² / reliabilityWeight`。
4. 再执行标准 Kalman 更新。

`c`、过程噪声和观察噪声由滚动回测选择。观察噪声还使用近期预测残差的 MAD 缓慢自适应，以适应用户成绩波动变化。

这相当于 Student-t / 重尾稳健滤波思想的工程化近似：保留递推效率，又避免一次意外 40 秒或一次幸运 skip 把状态大幅拉动。若以后实现精确 Student-t filter，必须以新 `modelVersion` 并通过同一回测门槛替换，不能静默改结果。

### 6.6 数据可靠权重

`reliabilityWeight` 取 `(0, 1]`，由事实决定，不由成绩快慢决定：

| 数据 | 更新规则 |
|---|---|
| 完整智能 Solve、序列连续、分段高置信 | 总体和对应 phase 使用完整权重 |
| 分段置信度中等 | 总体正常更新；受影响 phase 降权 |
| move gap 跨 phase | 不更新受影响 phase 的 time/move/pause 状态 |
| 手动计时 | 只更新总时间，权重低于完整智能 Solve；不更新 move/TPS/phase |
| +2 且完整还原 | 能力模型使用 raw execution time；+2 另存为比赛结果事实 |
| 未完成还原 DNF | 不更新 time/TPS 状态；更新 DNF 与数据质量统计 |
| 观察超时 DNF，但随后完整还原且 move 完整 | 可降权更新执行指标，保留 `inspectionDnf=true` |
| 用户明确标为设备异常 | 不更新水平状态，事实仍保留 |

不能因为成绩特别慢就自动删除；慢成绩只能通过稳健权重减少影响。用户排除必须有原因、可撤销且可审计。

### 6.7 scope 与冷启动

默认同一模型 scope：

- puzzle=3×3。
- method=CFOP。
- Cross 颜色。
- move 计数口径。
- 智能完整数据与仅手动时间的能力等级。

首版不使用其他用户的人群模型。新用户以个人前 5 次稳健中位数和宽先验初始化；数据不足时只显示“建立中”。更改 scope 不迁移旧状态，而是为新 scope 重建。

## 7. 七段预测与总量一致性

### 7.1 独立更新、联合输出

每个阶段独立更新，允许某次只缺一个阶段。展示前必须把七段与总体预测协调：

1. 得到总体 time 的后验样本。
2. 得到七段 time 的后验样本和 phase share。
3. 按各自不确定度，将七段之和与总体 time 做逆方差融合。
4. 保留七段相对占比，再缩放到融合后的总 time。
5. 每个预测样本都满足七段之和等于该样本的总 time。

不能先分别四舍五入再相加。UI 可因显示精度有 1 ms 级视觉误差，详情注明内部值一致。

### 7.2 稀疏 phase

- OLL / PLL skip 不作为 0 秒连续观察；另估计个人 skip 频率，仅作描述。
- 某阶段样本少时，向该用户该阶段的稳健中位数收缩，不向职业选手或全体用户收缩。
- F1–F4 仍按稳定完成顺序，不把不同 slot 强行当固定阶段；详情可再按 slot 分组。
- 数据不足时阶段显示区间，不补造精确 TPS。

## 8. 预测区间与在线校准

### 8.1 初始区间

前 30 个有效预测使用状态协方差、重尾观察噪声和逆变换生成 50% / 80% 区间。实现可使用固定种子的后验抽样，确保测试可复现；不得只用“中位数 ± 固定秒数”。

### 8.2 自适应保形校准

从第 30 个“先预测、后观察”的结果开始，为每个主要指标保存非一致性分数：

```text
score_t = abs(transformedActual - transformedMedian) / predictedScale
miss_t = 1, if actual outside current interval, else 0
q_(t+1) = clip(q_t + eta * (miss_t - alpha), qMin, qMax)
```

- 80% 区间的 `alpha=0.20`，50% 区间的 `alpha=0.50`。
- 只允许使用预测当时之前的数据，禁止把实际结果回填到同一把预测造成未来数据泄漏。
- 当成绩分布随训练漂移时，`q` 会随近期漏覆盖率缓慢调整。
- 校准器只调整区间宽度，不篡改中位预测。

这是 Adaptive Conformal Inference 思路在个人时间序列上的轻量实现。样本不足、近期 scope 改变或模型升级时回到“未校准”状态。

### 8.3 不确定性增长

以下情况必须增宽区间：

- 长时间未练习。
- 最近波动 MAD 上升。
- 设备数据完整性下降。
- phase 有效样本不足。
- 模型刚升级或 scope 刚建立。

页面不得因为用户长时间不练仍显示虚假的窄区间。

## 9. 回测、基线与自动降级

### 9.1 滚动起点回测

每次模型重建或版本升级，按时间顺序执行 rolling-origin backtest：

1. 只用第 `t` 把之前的数据预测第 `t` 把。
2. 保存预测中位数、50%/80% 区间、实际值和 scope。
3. 对总时间、TPS 派生量和七段 time 分别汇总。

### 9.2 必须比较的基线

- 最近 12 次中位数。
- 指数加权移动中位/均值的稳健实现。
- current ao12（仅作成绩基线，不处理 DNF 时需明确）。

### 9.3 质量门槛

至少评估：

- 平均绝对误差 MAE 与中位绝对误差 MdAE，秒和 log 空间各一份。
- 中位偏差，防止长期系统性高估或低估。
- 50% / 80% 区间实际覆盖率与平均宽度。
- 改善期的响应速度与单个极端值后的恢复速度。

默认上线门槛：

- 有至少 30 个有效先验预测。
- CTSS-1 的总时间 MdAE 不劣于最近 12 次中位数基线超过 3%。
- 最近足量窗口内，80% 区间覆盖率建议处于 72%–88%；不满足则不得显示“可靠”。
- 无未来数据泄漏测试通过。

若 CTSS-1 未过门槛，UI 自动退回“最近 12 次稳健估计”，仍显示区间和样本，不显示模型优越性文案。回退是正常安全机制，不是报错。

## 10. 从水平预测到提速建议

水平估计器只回答“现在大概是什么水平”，建议引擎回答“下一步练什么”。两者不可合成黑盒总分。

建议生成顺序：

1. 比较七段对总时间差距的可归因贡献。
2. 在最可能影响总成绩的阶段内，再比较 pause time、active TPS 和 move count。
3. 只有当差异超过不确定区间且样本门槛满足时，生成趋势建议。
4. 最多一条主建议和两条次建议，沿用 10 文档的证据区间、置信度和训练入口。

示例：

> F2 的当前预测比长期稳定水平慢 0.24 秒，差异主要来自阶段起始停顿；最近 20 个可靠样本中有 14 次出现同类差距。建议进行 5 分钟慢拧不断流训练。

禁止输出：

- “你真实水平就是 11.83 秒”。
- “你的观察能力只有 62 分”。
- “AI 认定你必须更换公式”。
- 只有一个不可解释综合分的“等级”。

## 11. 数据模型

### 11.1 SkillEstimateSnapshot

| 字段 | 含义 |
|---|---|
| id / scopeKey / metricKey | 唯一键与统计范围 |
| modelVersion / configVersion | 模型和参数版本 |
| stableMean / formMean | 变换空间中的长期与近期状态 |
| covariance | 2×2 对称协方差的三个独立值 |
| observationScale / residualMad | 当前观察噪声与稳健残差尺度 |
| sampleCount / reliableCount | 总观察和高可靠观察数 |
| lastObservationAt | 最近有效更新 |
| inputDigest | 输入 Solve 集合摘要 |
| status | BUILDING / PRELIMINARY / USABLE / CALIBRATED / FALLBACK |

Snapshot 是缓存，不是唯一事实源；删除后必须能从 Solve、MoveEvent 和 DerivedAnalysis 重建。

### 11.2 ForecastOutcome

| 字段 | 含义 |
|---|---|
| forecastId / solveId | 预测与随后实际 Solve |
| generatedAt / modelVersion | 预测时刻和模型版本 |
| scopeKey / metricKey | 统计范围与指标 |
| median / p10 / p25 / p75 / p90 | 预测快照 |
| actualValue | 后续真实值，Solve 确认后写入 |
| reliability | 实际观察可靠度 |
| nonconformityScore | 区间校准分数 |
| excludedReason | DNF、gap、scope 变化等 |

必须先写 forecast，再写 actual，数据库约束和测试防止未来数据泄漏。

### 11.3 SkillModelConfig

保存 `rho`、过程噪声、Huber `c`、MAD 窗口、校准 `eta`、样本门槛和创建来源。生产参数必须带版本与回测摘要，不从远端下载。

建议纯 Kotlin 服务：

| 服务 | 职责 |

| `RobustSkillStateEstimator` | 双状态预测、稳健更新、缺失观察跳过 |

## 13. 验收测试

### 13.1 赛后 UI

- 完整智能 Solve 显示成绩、HTM、实战 TPS、停顿率和“深度分析”。
- 手动 Solve 不出现伪造 move/TPS。
- 分析未完成不阻塞成绩确认，完成后按钮原位更新。
- gap、+2、DNF 和删除/撤销状态正确。
- 200% 字体、320 dp 窄屏和 TalkBack 可用。

### 13.2 赛前目标

- scramble 未完成时不显示，匹配后且开始前显示。
- Running 开始后隐藏；本把显示期间数值不跳变。
- 返回阈值 `x` 可严格刷新，`x+1 ms` 不可刷新。
- DNF 仍可 PB、无可能、无 PB、样本不足、+2 文案均覆盖。
- 专注模式和用户开关能隐藏提示，但不破坏统计。

### 13.3 模型性质

- 同一事件重放产生逐位一致或容差内一致的 Snapshot。
- 单个 10 倍慢异常值对预测的影响明显小于普通 Kalman / 均值基线。
- 连续改善数据使近期状态先响应，长期状态较慢跟随。
- 长期无练习后近期状态衰减、区间变宽。
- 缺失 F3 只阻止 F3 更新，不阻止可靠的总体和其他阶段。
- +2 使用 raw time 更新能力，正式纪录仍使用 final result。
- 未完成 DNF 不作为极慢时间污染状态。
- phase 预测样本之和等于总体预测样本。
- pause rate 逆变换始终处于 0–1。

### 13.4 回测与校准

- rolling-origin 在第 `t` 把绝不读取第 `t` 把及未来事实。
- 与最近 12 次中位数、EWMA、ao12 基线同 scope 比较。
- 覆盖率不达门槛时状态不会显示“可靠”。
- 模型不优于基线时自动进入 FALLBACK。
- modelVersion 变化后旧 ForecastOutcome 保留，新模型重新回测，不改写历史预测。

## 16. 方法参考

- [Kalman, 1960：A New Approach to Linear Filtering and Prediction Problems](https://asmedigitalcollection.asme.org/fluidsengineering/article-pdf/82/1/35/5518977/35_1.pdf)：递推状态估计的基础。
- [Roth et al., 2017：Robust Bayesian Filtering and Smoothing Using Student's t Distribution](https://arxiv.org/abs/1703.02428)：重尾噪声下的稳健滤波思路。
- [Gibbs & Candès, 2021：Adaptive Conformal Inference Under Distribution Shift](https://papers.neurips.cc/paper_files/paper/2021/hash/0d441de75945e5acbc865406fc9a2559-Abstract.html)：分布漂移下自适应覆盖校准的基础。
- [Zaffran et al., 2022：Adaptive Conformal Predictions for Time Series](https://arxiv.org/abs/2202.07282)：时间序列在线预测区间的校准参考。
- [Gibbs & Candès, 2024：Conformal Inference for Online Prediction with Arbitrary Distribution Shifts](https://jmlr.org/papers/volume25/22-1218/22-1218.pdf)：在线分布变化下区间有效性的进一步研究。

这些论文用于方法设计，不代表直接复制其代码，也不构成对本项目小样本数据一定达到特定统计保证的承诺。实际显示等级必须由本机 rolling-origin 回测和覆盖率门槛决定。
