# 03. 视觉设计系统

## 2026-09-26 · 当前实施方向

本轮用户确认采用《部落冲突》与《Tiny Glade（林间小世界）》融合风格，略偏前者。以下更新取代本文旧版中冲突的配色、圆角和阴影要求；功能色、数据可读性、低动态及自适应布局仍保留。

- 主方向：圆润厚实的卡片和按钮、可见的按下反馈，配柔和林地色与微缩魔方插画。保留公式／训练／计时／记录四入口，不增加任务、货币等游戏系统。
- 实际 token：深林字色 `#293B34`、雾绿背景 `#EEF0E6`、石灰白卡片 `#FFFDF5`、林地绿操作 `#3D7055`、浅叶绿 `#DDE9D4`、暖金强调 `#A56620`。魔方六面功能色独立保留。
- 标题与正文使用系统 SansSerif，标题加粗；公式和时间保留系统 Monospace。不引入未随工程交付的字体。
- 主要面板圆角 18–24 dp，详情浮层 26 dp；轻阴影、边框与顶部高光提供层次。原生 Canvas 微缩魔方为本地原创图形，不引入游戏截图或联网素材。
- 真实节奏播放器以时间为进度，停顿与动作一起倍速；估计时间、缺帧与时间异常使用明确文字，不能仅靠颜色表达。

实现入口：`app/src/main/java/com/cubetrace/app/WorkbenchStyle.kt` 与 `MainActivity.kt`。参考方向：[Tiny Glade 官方 Steam 页面](https://store.steampowered.com/app/2198150/Tiny_Glade/)。

以下为旧版设计记录，未冲突的交互与可访问性要求仍适用。

## 1. 设计方向

视觉主题是“校准工作台”：来自速度魔方的贴片平面、计时器的高密度数字和真实 move 的时间轨道，而不是常见的渐变仪表盘或儿童玩具风。

三个关键词：

- 精确：状态、时间和局面一眼可核对。
- 克制：真正的六色魔方面是视觉主角，界面颜色不与之争抢。
- 有节奏：公式 token、动作间隔和 CFOP 阶段形成独有的时间纹理。

标志性元素是 Move Rail。它同时是时间轴、动作阅读器和阶段导航，不是装饰性插画。

## 2. 主色系统

界面主色严格控制为六个 token：

| Token | HEX | 用途 |
|---|---|---|
| 墨石 Graphite | #18232B | 主文字、深色图标、轨道基线 |
| 雾面 Mist | #F2F5F6 | 页面背景、非选中区域 |
| 纸白 Paper | #FFFFFF | 工作面、编辑区、浮层 |
| 轨迹蓝 Track | #1463D6 | 主操作、当前步骤、选中状态 |
| 信号琥珀 Signal | #D98212 | 观察倒计时、待校准、低置信度 |
| 故障朱红 Fault | #C23B3B | DNF、连接错误、数据不完整 |

使用规则：

- 正常连接不依赖绿色，只使用轨迹蓝、连接图标和“已连接”文字。
- 大面积背景仅用雾面或纸白。
- Track、Signal、Fault 不在同一组件中竞争；每个状态只保留一个主信号色。
- 文字与背景按 WCAG AA 进行对比度验证；小字号不可使用低对比浅灰。

### 2.1 魔方功能色

六个面色属于数据，不属于 UI 品牌色：

| 面色 | 默认 HEX | 辅助符号 |
|---|---|---|
| 白 | #F7F7F4 | W |
| 黄 | #FFD500 | Y |
| 红 | #C41E3A | R |
| 橙 | #FF7A00 | O |
| 蓝 | #0051BA | B |
| 绿 | #009E60 | G |

块间缝隙默认 #1D252B。用户可建立 V10 AI 颜色 profile；色觉辅助模式在贴片中央叠加字母或纹理。示意图不可只靠颜色区分 case 的关键贴片，还需用描边或明暗层级表示。

## 3. 字体角色

| 角色 | 字体 | 用途 |
|---|---|---|
| 中文界面 | Noto Sans SC | 标题、正文、按钮和辅助信息 |
| 计时数字 | Barlow Condensed SemiBold | 大号时间、阶段时间、统计数字 |
| 公式与数据 | JetBrains Mono | move token、公式文本、固件与诊断值 |

三种字体均采用可随应用分发的开放字体版本，并在第三方通知中保留 OFL 许可证。

### 3.1 字号与行高

| 样式 | 字号 / 行高 | 字重 |
|---|---|---|
| 大计时 | 72–112 sp / 0.92 | 600 |
| 页面标题 | 24 sp / 32 sp | 650 |
| 区块标题 | 18 sp / 26 sp | 600 |
| 正文 | 15 sp / 23 sp | 400 |
| 辅助 | 13 sp / 19 sp | 400 |
| 公式 token | 16 sp / 24 sp | 500 |
| 统计数字 | 24–36 sp / 1.0 | 600 |

大计时使用等宽数字特性，避免毫秒跳动造成布局抖动。公式 token 不允许自动替换 prime 符号或合字。

## 4. 间距与形状

- 基础网格：4 dp。
- 页面水平留白：手机 16 dp，宽屏 24 dp。
- 同组元素：4 或 8 dp。
- 区块之间：20 或 24 dp。
- 主触控高度：48–56 dp。
- 小按钮可视图标 24 dp，但触控范围仍为 48 dp。
- case 卡片圆角：8 dp。
- 浮层圆角：12 dp。
- move token 圆角：4 dp。

魔方本身由清晰平面和硬边构成，因此界面不使用过度膨胀的胶囊和超大圆角。阴影只用于实际悬浮关系；普通区块用 1 dp 分隔线或背景层级，不把所有内容装进阴影卡片。

## 5. 栅格与密度

### 手机竖屏

- 4 列逻辑栅格，16 dp 边距，8 dp gutter。
- 公式首页默认 2 列 case；字体放大时 1 列。
- 计时与三维画面可跨全宽。
- 复盘阶段表允许水平滚动，但阶段名和时间列固定。

### 横屏或宽屏

- 8 或 12 列逻辑栅格。
- 主对象和信息面板按 5:7 或 1:1 分栏。
- 最大内容宽度 1200 dp，超过后保留居中工作区，不无限拉长 Move Rail token。

## 6. 核心组件

### 6.1 设备状态胶囊

胶囊是少数允许全圆角的组件，因为它表达连续设备状态。

内容顺序：

    设备图标 · V10 AI · 状态文字 · 电量

状态：

- 未连接：雾面背景、墨石文字。
- 连接中：轨迹蓝细进度线、“连接中”。
- 已连接：轨迹蓝图标、“已连接 · 82%”。
- 待校准：信号琥珀、“需要校准”。
- 异常：故障朱红图标、“同步中”或具体错误。

### 6.2 Case 卡片

- 左侧或上部为固定比例局面图。
- 名称和编号形成第一阅读层。
- 首选公式采用 JetBrains Mono，最多两行。
- 掌握度用“3 / 5 熟悉”和细刻度共同显示。
- 收藏按钮有稳定位置，不因公式长度变化而移动。

### 6.3 Move token

- 默认：透明背景、墨石文字。
- 当前：轨迹蓝实底、纸白文字。
- 已播放：轨迹蓝浅色描边。
- 转体：空心、较窄，并有旋转图标。
- 无效或无法解析：故障朱红下划线和错误说明。
- 手法分组可用细竖线，不使用多层嵌套括号背景。

### 6.4 Move Rail

- 基线厚 2 dp。
- CFOP 阶段线厚 4 dp，配文字段名。
- 停顿超过阈值时真实拉开间距；超过视图上限后用折断符号压缩。
- 播放游标宽 2 dp，顶部带可拖动把手。
- 时间缩放最小保证 token 仍能点击，最大允许观察单步间隔。

### 6.5 时间与统计

- 主要计时只显示一个大数字，不在旁边并列多个同等权重指标。
- 毫秒始终三位；超过一小时后仍保持可扫读层级。
- +2 在时间右上角显示，不把原时间预先改成字符串。
- DNF 显示 DNF，并在次级行保留原始时间。
- 图表使用直接标注，不要求用户来回对照图例。

### 6.6 三维视图

- 默认背景与页面融为一体，不套厚重黑色画框。
- 下方固定提供置正、跟随 / 锁定和全屏。
- 同步中时使用非遮挡式扫描线和文字，仍可看到最后可信局面。
- 用户拖动视角后，gyro 跟随暂时暂停，并出现“恢复跟随”。

## 7. 图标与图形

- 使用统一 2 dp 线宽的圆角线性图标。
- 魔方面和 move 图形使用正交平面与清晰箭头，保持技术示意感。
- 不使用无含义的闪光、火焰或奖杯作为熟练度主图标。
- 阶段图 Cross / F2L / OLL / PLL 由程序根据状态生成，不使用厂商海报资产。
- 错误图标同时配文字，警告色不用于普通装饰。

## 8. 动效

动效只用于表达状态变化：

| 场景 | 建议 |
|---|---|
| 单层转动 | 90–130 ms，线性进入、轻微缓出 |
| 公式播放 | 根据用户速度连续排队，不叠加弹性回弹 |
| 页面切换 | 160–220 ms 淡入与小幅平移 |
| 设备连接 | 状态线循环，不旋转整个魔方 |
| Move Rail 游标 | 与回放时钟严格同步 |
| 阶段切换 | 阶段线颜色和标签淡变 120 ms |

逻辑状态更新先于动画。事件积压时，动画压缩或跳到最终状态。开启系统降低动态效果后：

- 取消页面位移。
- 三维回放改为单步切换或极短转动。
- 四元数朝向以较低频率更新，不做惯性。

## 9. 声音与触觉

- 计时 Ready：一次短而轻的振动。
- 观察 8 秒 / 12 秒：两种可区分的振动节奏，可关闭。
- Solve 自动停止：一次清晰短振。
- 连接断开：不在每次自动重试时连续振动，只在计时受影响时提示一次。
- 训练正确 / 错误：触觉不同，但不以声音作为唯一反馈。

## 10. 页面视觉重点

| 页面 | 唯一主角 | 次级信息 |
|---|---|---|
| 公式首页 | case 局面网格 | 筛选与掌握度 |
| Case 详情 | 三维局面 + 公式 token | 变体和笔记 |
| 训练 | 当前 case | 队列进度 |
| 计时 | 时间 | scramble、设备和最近成绩 |
| 复盘 | 三维 + Move Rail 联动 | 阶段表与诊断 |
| 记录 | 一条当前趋势 | 摘要与 Solve 列表 |

每个页面不得同时出现两个同等大小的主按钮。页面内的“开始训练”“开始计时”“查看复盘”等核心动作固定在拇指可达区域。

## 11. 设计验收清单

- 在去掉品牌名后，仍能从 Move Rail 和 case 表达识别这是魔方工具。
- 六色贴片是页面最鲜艳的对象，UI 信号色没有抢夺视觉层级。
- 119 个 case 的列表看起来像可工作的索引，不像营销卡片墙。
- 大计时在 320 dp 宽、系统字体 200% 时不裁切。
- 连接、同步、待校准、错误均有文字，不只换颜色。
- TalkBack 可完成连接、训练、计时、成绩确认和备份。
- 低动态模式下不存在必须依赖动画才能理解的状态。
- 所有预设 case 图均可由数据重建，没有参考图片的裁切残留。

## 12. 自我审查与取舍

- 风险：三种字体增加安装包体积。处理：按实际字符子集打包，若收益不足，计时数字回退到 Noto Sans 的等宽数字特性。
- 风险：六色魔方与 Track / Signal / Fault 同屏时颜色较多。处理：UI 信号色只占小面积，图表和区块优先用墨石、雾面和线型区分。
- 风险：Move Rail 信息密度高。处理：默认显示动作与阶段，停顿数字、转体和诊断逐级展开；新用户先看到阶段摘要。
- 风险：受限 WebView 与原生组件可能有轻微字体和色差。处理：共享 token JSON，并做截图回归；WebView 不自行定义第二套主题。
- 取舍：首版优先完成浅色主题。若深色主题无法保证贴片颜色、对比度和三维背景一致，不以简单反色方式仓促上线。
