# 方迹 0.4.1

2026-10-03，versionCode 13。基于 v0.4.0，应用 ID、数据库结构和正式签名保持不变。

## 更新

- 公式页的全部、F2L、OLL、PLL 四个阶段同屏显示。
- 三维回放的上一步、重置、下一步、播放按钮均分宽度，播放按钮完整显示。
- 回放从 Compose 面板逐帧驱动改为原生 View 直接采样共享单调时钟。文字和进度条以 20 Hz 更新，面转以原生显示节奏绘制；提前跳过背面不必要的几何变换及着色。
- 底部导航改为紧凑的半透明悬浮胶囊，内容可以从后方滚过，末尾留白保证最后一项可达。

## 验证与边界

- 48 项分析回归、11 项时间轴/时钟检查、119 个案例检查通过；正式构建、lint 通过（0 errors、14 warnings）。
- Android 12 真机验证四个阶段、四个播放按钮均完整显示，浮动导航可切换页面；暂停、0.5×/2×、单步、拖动、最终 89/89 步还原通过。
- 覆盖升级前后的备份用户数据逐字节一致；没有卸载或清空应用。最终安装包与发布包 SHA-256 一致。
- 同一条 19.549 秒成绩各采样约 8 秒：旧版真实/匀速 P95 帧耗时为 14/15 ms；最终包完成 Android 本地代码优化后为 17/15 ms，系统卡顿帧比例约 0.54%/0%。这不是受控实验，新安装的代码优化状态、温度和调度会影响结果，不能据此宣称整体帧耗时降低。实际改进是将面转采样与面板重组解耦；不承诺所有设备达到某个固定 FPS。
- 保留录制时间点和停顿。同一时间戳的多个动作仍瞬时到位，不编造包内间隔；可使用匀速模式逐步观察。

## 安装

一般安装和从 0.4.0 升级请选择 `FangJi-CubeTrace-v0.4.1-release.apk` 直接覆盖安装。`legacy-upgrade.apk` 仅供历史 debug 签名安装迁移，两个包功能相同。不要卸载或清除数据。
