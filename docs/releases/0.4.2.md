# 方迹 0.4.2

2026-10-11，versionCode 14。基于 0.4.1，保留应用 ID、数据库与正式签名，可直接覆盖安装。

## 更新

- 横屏计时左侧保留魔方，右侧展示时间、打乱和控制，支持独立滚动。
- 训练和公式详情采用左局面、右公式及操作；播放公式时三维魔方留在左侧。训练压缩头部，答案和评分优先呈现。
- 记录采用左成绩列表、右选中复盘，切换成绩保留列表滚动位置；统计概览可展开，返回键关闭当前复盘。
- 独立宽屏复盘支持三维回放与分析并排；按实际窗口尺寸适配，竖屏和窄窗口保留单栏。

## 验证与边界

- 最终 release 构建与 lint 通过（0 errors、14 warnings）。本次仅调整界面布局，没有修改公式引擎、回放时间轴、蓝牙协议或数据结构。
- 华为 MRX-W29、Android 12：检查 2560×1600 横屏、1600×2560 竖屏，以及临时模拟的 2560×1200 短横屏窗口；测试后恢复原显示和自动旋转设置。
- 计时长按准备／轻触开始／停止／放弃、训练答案揭示、评分按钮可达、公式演示与右栏滚动、记录选中与列表位置保持、回放 2×与暂停通过检查。
- 0.4.1 覆盖升级后仍保留 10 次原成绩；最终备份用户数据与升级前逐字节一致。测试手动成绩未保存，训练评分未写入。未重新连接实体魔方录制新数据，不据此增加蓝牙兼容性或 FPS 承诺。
- 正式 APK 通过 API 26–27 和 28+ 签名校验、ZIP 对齐校验；平板安装包、桌面副本与发布 APK 哈希一致。

## 安装

选择 `FangJi-CubeTrace-v0.4.2-release.apk` 直接覆盖安装，不要卸载或清除数据。`legacy-upgrade.apk` 仅用于历史 debug 签名安装迁移，两个包功能相同。

APK、对应源码、安装说明、许可证和 SHA-256 校验和一起提供。签名连续性与构建说明见 [SOURCE.md](../../SOURCE.md)。
