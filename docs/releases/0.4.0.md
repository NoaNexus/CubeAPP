# 方迹 0.4.0

2026-09-26，versionCode 12。基于 v0.3.1（`0273cd3`），数据库结构保持不变。

## 更新

- 119 个公式案例提供对应练习状态的自动打乱，可复制并进入指定案例练习。
- 三维复盘新增真实节奏，按保存的动作时间点保留停顿，支持 0.5× / 1× / 2×、暂停续播、拖动和单步；保留匀速观察。
- 整体采用圆润立体的按钮、卡片与柔和林地配色，四个主要页面及详情统一视觉。
- 修正权限撤销时的蓝牙异常处理、Android 8 系统栏兼容和关于页版本显示。

## 验证

- 48 项分析回归、9 项时间轴检查、119 个案例精确局面检查通过。
- debug 构建和单测源码编译通过；最终 release 构建与 lint 通过（0 errors、14 warnings）。
- Android 12 真机从 0.3.1 覆盖升级，公式打乱复制、指定练习、计时页面、历史成绩回放通过。0.5× / 2× 连同停顿缩放，暂停期间进度不变，续播、时间定位、匀速、单步及还原终点通过检查；最终包另以 100 步历史成绩验证暂停、2× 与还原终点。
- 升级前后备份的 `user-data.jsonl` 长度及 SHA-256 完全一致，保留原有 274 条成绩。备份和含用户数据的测试材料不纳入源码或发布附件。
- 最终手机安装 APK 与发布 APK 的 SHA-256 一致。普通包与旧签名迁移包分别通过 API 26–27、API 28+ 签名检查。

## 安装

一般安装或从 0.3.1 升级请选择 `FangJi-CubeTrace-v0.4.0-release.apk`，直接覆盖安装。不要卸载或清除数据。

仅旧版 debug 签名安装需要 `legacy-upgrade.apk`。Android 8 上已使用正式签名的安装必须使用普通 `release.apk`。两个包功能相同，签名连续性说明见 [SOURCE.md](../../SOURCE.md)。

## 边界

真实节奏忠实使用已记录的时间证据；同时间戳动作即时到位，不猜测包内间隔，面转过渡是视觉示意。估计或未知时间会标注，异常时间轴回退为匀速观察。本轮未连接实体魔方录制新成绩，未新增蓝牙协议或连续陀螺仪姿态验收结论。

源码、APK 校验和与许可证随 GitHub Release 提供。Wrapper 固定 Gradle 9.4.1 及分发包 SHA-256；使用 Java 17 和 Android SDK 35 构建。签名凭据始终位于仓库外。
